# 🔐 Password Generator



A command-line Python program that generates strong, random passwords
based on user preferences such as length and character types.

Built as part of the **Synent Technologies Python Development Internship**
— Task 4 (Basic Level).

---

## 📌 Project Description

This project takes user input to customize a password by:
- Choosing the desired length
- Selecting which character types to include

The program validates every input, handles errors gracefully,
and allows the user to generate multiple passwords in one session.

---

## 🎯 Objective

- Understand how randomness works in Python
- Build a modular, function-based program
- Handle user input and validate it properly
- Practice using Python's built-in string and random modules

---

## ✨ Features

- ✅ Custom password length
- ✅ Choose character types:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Digits (0-9)
  - Symbols (!@#$%...)
- ✅ Input validation (handles letters, negatives, zero)
- ✅ Minimum one character type enforced
- ✅ Generate multiple passwords in one session
- ✅ Clean and readable CLI output

---

## 🧠 Concepts Used

| Concept | Usage |
|---|---|
| `string` module | Ready-made character sets |
| `random` module | Random character selection |
| Functions | Modular, reusable code blocks |
| while loop | Repeat until valid input |
| try / except | Handle invalid inputs gracefully |
| List + join() | Efficient password assembly |
| Boolean logic | Character type selection |
| Tuple unpacking | Return multiple values cleanly |
